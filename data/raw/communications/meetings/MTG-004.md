# Meeting Summary
The review of INC-1042 revealed a security breach caused by a deprecated SSH key on a legacy backup server that should have been decommissioned. While no data exfiltration occurred, the incident highlighted a systemic gap in the offboarding process (ITSEC-004). The team agreed to move toward automated key rotation and a full inventory audit of all legacy VMs.

# Decisions Taken
1. **Remediation:** Implement an automated SSH key audit script to identify and revoke keys associated with inactive employees.
2. **Infrastructure Audit:** Perform a complete sweep of all legacy subnets in LKO and BLR to identify and decommission "ghost" servers.
3. **Policy Update:** Revise the ITSEC-004 Employee Offboarding Checklist to include a mandatory legacy infrastructure audit.

# Open Issues
1. **Key Management:** We still rely on fragmented key storage for some legacy systems; we need a more centralized secret management solution (e.g., HashiCorp Vault).
2. **Detection Latency:** The breach was detected after 4 hours; we need to improve the alerting threshold for unusual SSH logins.
