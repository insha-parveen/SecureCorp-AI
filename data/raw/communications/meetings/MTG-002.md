**09:00**

When the hybrid retrieval returns a high volume of long chunks—especially from those technical manuals we ingested for ACME—the cross-encoder just chokes. We're seeing request times exceed 10 seconds on about 5% of the queries.

**09:04**  
**Neha Kapoor:**  
I've been digging into the patterns. It's not just the number of chunks, but the token length. The reranker is doing a full cross-attention over the query and each candidate. If we have 50 candidates and half of them are 500 tokens each, the quadratic complexity of the attention mechanism kills us.

**09:06**  
**Priya Sharma:**  
Could we just truncate the chunks before they hit the reranker? If we only pass the first 200 tokens, would we lose too much context for the reranking decision?

**09:08**  
**Sarah Jenkins:**  
That's a risk. If the key evidence is at the end of a long chunk, truncation might cause the reranker to push a highly relevant chunk down the list. We need to be careful. 

**09:10**  
**Sunita Rao:**  
What about the candidate set size? We're currently at 50. If we drop to 25, does the Recall@10 take a hit?

**09:12**  
**Neha Kapoor:**  
I ran some quick tests yesterday. For simple factual queries, Recall@10 is almost identical. For complex, multi-hop queries, we lose about 2-3%. I think that's an acceptable trade-off for a 50% reduction in reranking latency.

**09:15**

# Meeting Summary
The team discussed the stability issues of the Project Orion Alpha, specifically the 504 timeouts caused by the cross-encoder reranker. The primary cause is the quadratic complexity of attention when processing large chunks. Proposed solutions include reducing the candidate set size from 50 to 25 and implementing a scope-aware semantic cache. Priya reported a slight improvement in retrieval by tuning the RRF constant.

# Decisions Taken
1. **Candidate Set Reduction:** Experiment with reducing the reranker candidate set to 25 to lower latency.
2. **Semantic Cache:** Proceed with a proposal for a scope-aware semantic cache using Redis.
3. **RRF Tuning:** Continue monitoring the impact of changing the RRF constant from 60 to 55.

# Open Issues
1. **Token Truncation:** Debate remains on whether truncating chunks before reranking will negatively impact Recall for long-form evidence.
2. **Cache Threshold:** The exact similarity threshold for semantic cache reuse is yet to be determined.
