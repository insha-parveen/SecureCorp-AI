# Meeting Summary
The meeting focused on the UAT status for ACME Manufacturing. While retrieval accuracy is highly praised, significant latency issues (5-8 seconds) are being reported in both Dubai and Singapore. This is attributed to a reranker bottleneck caused by long chunks in ACME's technical manuals. Data normalization has improved significantly since switching to structured JSON ingestion.

# Decisions Taken
1. **Performance Target:** The team aims to reduce query latency to under 3 seconds for the final sign-off.
2. **Technical Fix:** The engineering team will prioritize reranker optimization and semantic caching for the ACME corpus.
3. **Data Ingestion:** Standardize on structured JSON for all future document uploads from ACME.

# Open Issues
1. **SLA Compliance:** The current 5-8 second latency is above the promised SLA and could jeopardize final sign-off.
2. **Cache Effectiveness:** Uncertainty remains regarding how much the semantic cache will improve performance for exploratory (non-repeated) queries.
